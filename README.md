# How to run

## Prerequisites

- ROS 2 Lyrical with `ros_gz_sim`, `ros_gz_bridge` and Gazebo (Jetty) installed, at `/opt/ros/lyrical`
- A display available if you want the Gazebo GUI and the YOLO window (inside a container, pass through X11/Wayland)
- Python 3 with `venv`

## First time only

```bash
./setup.sh
```

This creates `.venv` (with access to the system ROS packages), installs `requirements.txt`, installs `colcon` into the venv, generates the world file and builds the workspace. It takes a few minutes because of PyTorch.

## Every session

Run these in **every new terminal** (`source`, not `./`):

```bash
source env.sh
```

You should see `(.venv)` in your prompt. If `env.sh` prints a warning about `colcon`, see Troubleshooting.

## After changing code

```bash
source env.sh
colcon build --symlink-install
source env.sh        # pick up the new install/
```

Always build from a terminal where `env.sh` was sourced. Building with the system `colcon` bakes the wrong Python into the nodes, and they crash with `No module named 'ultralytics'`.

## Run the system

```bash
source env.sh
ros2 launch surveillance_sim sim_launch.py
```

This starts three things: Gazebo with the arena, the camera bridge (`ros_gz_bridge`) and the YOLO node. Check it in a second terminal (run `source env.sh` there too):

```bash
ros2 topic list | grep -E "image|person|goal"
ros2 topic hz /surveillance_camera/image_raw
ros2 topic echo /person_activity
```

## Regenerating the world

The world file is generated by a script. After editing `generate_world.py`:

```bash
python3 src/surveillance_sim/scripts/generate_world.py
colcon build --symlink-install
```

## Troubleshooting

| Symptom | Cause and fix |
|---|---|
| `No module named 'ultralytics'` when the node starts | Built with the wrong `colcon`. Run `source env.sh`, then `rm -rf build install log` and rebuild. Check with `head -1 install/perception/lib/perception/yolo_surveillance`, which must point into `.venv`. |
| `env.sh: WARNING: colcon is not the venv's` | Run `pip install --ignore-installed colcon-common-extensions`, then `hash -r`. |
| `_ARRAY_API not found` | NumPy version clash with `cv_bridge`. Run `pip install "numpy<2"`. |
| `Could not load the Qt platform plugin "xcb"` | Run `unset QT_QPA_PLATFORM_PLUGIN_PATH` before launching. |
| Gazebo starts but there are no camera topics | Check the Gazebo terminal for `ogre2` / rendering errors. |
| Walking actor is missing | The mesh downloads from Fuel on first launch, so it needs internet once. |
| Stale world after regenerating | Rebuild with `colcon build --symlink-install`. |

## Rules for contributors

- Never commit `.venv/`, `build/`, `install/` or `log/`. The built launchers contain absolute paths, so each person builds their own.
- After moving or renaming the project folder, delete `.venv`, `build`, `install` and `log` and rerun `./setup.sh`.
- New Python dependencies go in `requirements.txt`, not into your own environment.
